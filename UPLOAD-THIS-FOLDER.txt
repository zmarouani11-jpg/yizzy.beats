Steps:
1. Open the repository for https://marouani845-code.github.io/Yizzy.beats/
2. Add file > Upload files.
3. Drag in index.html, styles.css, script.js, and the whole assets folder from this extracted folder.
4. Commit changes to the branch used by GitHub Pages.
5. Wait for Pages to redeploy, then hard-refresh the site with Ctrl+F5.

Audio is provided as MP3 for broad browser support. The HTML references assets/beats/*.mp3 and cover images at assets/beats/*.jpg.
