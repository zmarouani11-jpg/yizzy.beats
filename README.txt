YIZZY.BEATS website update

WHAT'S INCLUDED
- index.html: the website page
- styles.css: responsive design and layout
- script.js: mobile menu, year, and one-at-a-time beat playback
- assets/beats/: five beat cover images and audio previews extracted from the supplied MP4 files

THE NEW SENTENCE AT THE TOP

UPLOAD TO GITHUB PAGES
1. Extract this ZIP on your computer.
2. Open your GitHub repository: https://github.com/marouani845-code/edfs
3. If you want to keep a backup, download the current repository files first.
4. In the repository, choose Add file > Upload files.
5. Upload index.html, styles.css, script.js, README.txt, and the whole assets folder (including assets/beats).
6. Commit the changes to the branch/folder currently used by GitHub Pages (usually main and the repository root).
7. Wait a minute, then refresh https://marouani845-code.github.io/edfs/ with Ctrl+F5.

IMPORTANT
- The beat players use .m4a audio files extracted from your supplied MP4 videos; the cover images are still frames from those videos.
